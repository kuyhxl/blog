## 1. 오늘 배운 것
1.  Gradle
	- `build.gradle` script
	- Groovy
	- Maven Repository
2. 네트워크 & 웹서버
	- IP address & Port number
	- Web Server
		- e.g. Apache, Nginx
		- Web servlet(Web Container)
		- role
			- Static Contents Management
			- Dynamic Requests Forwarding
	- WAS(Web Application Server)
		- e.g.Tomcat
	- Spring Boot
		- XML -> `@`annotation
		- Apache Tomcat
3. HTTP
	- Method
		- GET/POST/PUT/PATCH/DELETE
	- Header
		- State Code
	- Payload - json
4. Test Code
	- JUnit
5. Lombok
	- `@Getter`, `@Setter`
	- `@RequiredArgsConstructor`
6. application.properties
7. MVC Design Pattern
	- Model
	- View
	- Controller
8. Front Controller (DispatcherServlet)
	- `@Controller`
	- `@GetMapping`, `@PostMapping`
9. Page & Data Return
	- Static Page - `static`
	- Dynamic Page - Thymeleaf
	- Data Return - json
		- `@ResponseBody`
		- `@RestController` = `@Controller` + `@ResponseBody`
