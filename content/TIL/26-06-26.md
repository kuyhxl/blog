## 1. 오늘 배운 것
1. Jackson
	- json(XML, YAML, CSV...) <-> Object
		- Serialization
		- Deserialization
	- `ObjectMapper`
		- `.writeValueAsString();` -> Getter 필요
		- `.readValue()` -> Getter or Setter and 기본생성자 필요
2. Path Variable
	- `localhost:8080/hello/request/star/Robbie/age/97`
3. Request Param(Query String)
	- `localhost:8080/hello/request/from/param?name=robbie&age=95`
	- `@RequestParam`생략 가능
	- `@RequestParam(requrie = false)`
4. HTTP -> Object
	- `@ModelAttribute` -> Setter and 기본 생성자 필요
		- 생략가능하다 (simple value type이라면 RequestParam 아니라면 ModelAttribute)
		- 생략 불가능한 예외 상황이 존재한다.
	- `@RequestBody`필요 상황: HTTP body에 json 데이터가 있을 때 -> java object
5. DTO(Data Transfer Object)
	- 클라이언트에서 보내오는 데이터 처리 & 서버 계층 간 이동
	- Database와 소통하는 Java Class(Entity)를 그대로 클라이언트에 반환하지 않고 DTO로 변환해서 반환
	- `RequestDto`, `ResponseDto`
6. Database
	- DBMS(Database Management System)
	- RDBMS(Relational DMBS)
	- SQL(Structured Query Language)
		- DDL(Data Definition Language)
			- CREATE
			- ALTER
			- DROP
			- TRUNCATE
		- DCL(Data Control Language)
			- GRANT
			- REVOKE
		- DML(Data Manipulation Language)
			- INSERT
			- UPDATE
			- DELETE
			- SELECT
				- JOIN
		- 제약 조건
			- AUTO_INCREMENT
			- NOT NULL
			- UNIQUE
			- PRIMARY KEY
			- FOREIGN KEY
				- CASCADE
7. JDBC(Java Database Connectivity)
	- Application <-> MySQL
	- `JdbcTemplate` (Spring JDBC)
	- JDBC Driver
## 2. 아직 모르겠는 것
- 전반적으로 MySQL 개념과 문법 숙지 필요
- 직렬화 역직렬화 과정에서 Getter or Setter 기본생성자가 왜 필요한지 한번 더 이해 필요
- 테이블 제약조건 이해 필요
- ORM
